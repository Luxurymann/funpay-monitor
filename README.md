# FunPay Price Monitor 💸

Автоматический скрипт на языке Go, который следит за ценами ваших конкурентов на торговой площадке FunPay. Программа автоматически парсит ваш профиль, находит выставленные вами лоты, после чего проверяет их категорию и находит минимальную цену у конкурентов. 

Если конкурент демпингует или, наоборот, сильно завышает цену (на 15% и более), программа оповещает вас об этом.

## Основные возможности 🚀

1. **Обход защиты Cloudflare**: Скрипт использует `chromedp` (невидимый Chrome браузер) для загрузки страниц, поэтому FunPay не блокирует его как обычного бота.
2. **Исключение собственных лотов**: Скрипт автоматически понимает, какие лоты ваши (по вашему ID), и не считает вас вашим же конкурентом.
3. **Продвинутый поиск по нескольким названиям**: Если ваш предмет называется по-разному, вы можете использовать символ `|` в названии лота. 
   - *Пример:* `seabeast core | sb core`. Программа будет искать оба варианта и считать за конкурентов тех, у кого в названии есть хотя бы одна из этих фраз.
4. **Умный фильтр скрытых элементов**: Парсер отбрасывает предметы, которые FunPay подгружает, но скрывает из поиска, тем самым предотвращая ложные "дешевые" цены.
5. **Красивые Markdown-отчеты**: Все результаты проверок аккуратно логируются в файл `report.md` в виде удобных таблиц.

## Установка и запуск 🛠️

### 1. Установка зависимостей
Убедитесь, что у вас установлен **Go** и браузер **Google Chrome** (или Microsoft Edge).
Скачайте все необходимые библиотеки командой в терминале:
```bash
go mod tidy
```
*(Или вручную `go get github.com/chromedp/chromedp`, `github.com/PuerkitoBio/goquery`, `github.com/joho/godotenv`, `github.com/fatih/color`)*

### 2. Настройка файла .env
Скопируйте файл `.env.example` в `.env` (если вы этого еще не сделали) и настройте его:

```env
# Ссылка на ваш профиль FunPay (отсюда берутся ВАШИ лоты)
PROFILE_URL=https://funpay.com/users/1234567/

# Ссылка на общую категорию вашей игры, где нужно искать конкурентов
CATEGORY_URL=https://funpay.com/lots/919/

# Как часто проверять цены (в секундах)
CHECK_INTERVAL_SECONDS=300
```

### 3. Запуск
Откройте терминал в папке проекта и запустите команду:
```bash
go run main.go
```

## Как смотреть отчеты 📊
Каждые `CHECK_INTERVAL_SECONDS` программа будет выводить результаты прямо в консоль. 
Параллельно в папке проекта появится файл `report.md`. Вы можете открыть его в Visual Studio Code или загрузить на GitHub — он отобразится как красивая цветная таблица с историей всех проверок!

## Возможные статусы 🚦
- 🔴 **Сильно дешевле**: Найден конкурент с ценой на 15% (и более) ниже вашей.
- 🟢 **Сильно дороже**: Минимальная цена конкурента на 15% (и более) выше вашей (отличный повод поднять свою!).
- 🟡 **Разница до 15%**: Конкурент есть, но его цена примерно равна вашей.
- ⚪ **Нет конкурентов**: Вы — единственный продавец этого предмета в данный момент.
- ❌ **Ошибка**: Ошибка при парсинге или загрузке страницы.
